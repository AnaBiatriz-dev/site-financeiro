# 💰 Site Financeiro

Aplicação web de finanças pessoais desenvolvida para organizar e acompanhar a vida financeira de forma simples e intuitiva.

## 📌 Sobre o projeto

O Site Financeiro é um projeto desenvolvido com o objetivo de criar uma aplicação para gerenciamento financeiro pessoal.
A ideia é reunir em um só lugar informações como gastos, compras, cartões e faturas, facilitando o acompanhamento das finanças.
Este projeto também faz parte da minha jornada de aprendizado em desenvolvimento web.

## 🚀 Tecnologias

- HTML5
- CSS3
- JavaScript

## ✨ Funcionalidades

- [ ] Dashboard financeiro
- [ ] Controle de gastos
- [ ] Registro de compras
- [ ] Controle de cartões
- [ ] Acompanhamento de faturas
- [ ] Organização por mês
- [ ] Cálculo de valores e parcelas
- [ ] Interface responsiva
